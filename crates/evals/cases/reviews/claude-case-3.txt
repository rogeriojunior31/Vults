**Problems, most serious first**

1. **`nums.py:6` — `clamp` has its bounds swapped, so it is wrong for every input inside the range.** It computes `max(hi, min(lo, x))`. The inner `min(lo, x)` takes the lower bound where it should take the upper, and the outer `max` then takes the upper bound where it should take the lower. The result is that any `x` at or below `hi` comes back as `hi`. Running the function on the branch confirms it:
   - `clamp(5, 0, 10)` returns `10`, expected `5`
   - `clamp(-3, 0, 10)` returns `10`, expected `0`
   - `clamp(0, 0, 10)` returns `10`, expected `0`
   - `clamp(2.5, 1.0, 3.0)` returns `3.0`, expected `2.5`
   - Only inputs at or above `hi` (`42` and `10` against `[0, 10]`) come out right.

   The fix is `return max(lo, min(hi, x))`.

**Criteria**
