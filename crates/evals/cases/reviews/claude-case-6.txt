## Findings

1. **`calc.py:8`: `safe_div` divides by the wrong operand.** It returns `b / a` where the spec requires `a / b`. This fails the first criterion, "safe_div(a, b) returns a / b". Results I observed: `safe_div(6, 3)` returns `0.5` instead of `2.0`, `safe_div(1, 4)` returns `4.0` instead of `0.25`, and `safe_div(-6, 3)` returns `-0.5` instead of `-2.0`. The fix is `return a / b`.
