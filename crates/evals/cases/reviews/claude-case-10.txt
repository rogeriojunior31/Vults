**Criteria**
- `parse(text)` maps each key to its value: met for simple `key=value` lines, including surrounding whitespace, blank lines, and empty values.
- Values may contain `=`: **not met.** `parse("url=http://x/?a=1&b=2")` raises `ValueError: too many values to unpack (expected 2, got 4)`. The same happens for `token=abc==`.

**Problems, most serious first**

1. **`conf.py:9`**: `line.split('=')` splits on every `=`, so any value containing `=` crashes the function. This fails the second criterion directly. The fix is `line.split('=', 1)`, which splits only on the first `=`.

2. **`conf.py:9`**: A line with no `=` (for example `novalue`) raises `ValueError: not enough values to unpack`. One malformed line discards the entire result. 4. **`conf.py:9`**: An empty key is accepted, so `"=x"` returns `{'': 'x'}`. This is likely unintended, and a malformed line should probably be rejected or skipped.
