# Vults
<!-- source: fac52ad71713 -->

O Vults mostra seus agentes de código na sua área de trabalho e te dá um companheiro para trabalhar junto.
**O bando**: cada sessão do Claude Code, Codex, Antigravity, OpenCode, Hermes Agent, Qwen Code, Copilot CLI,
Cursor, Factory Droid e Kimi Code é um urubu que mostra o que está fazendo; aprove ou negue as
permissões dele com um clique, responda às perguntas dele, pule para o terminal dele e receba
novidades do GitHub, do GitLab e do Gitea. **Zeca**: um urubu-de-cabeça-preta que conversa com você
pelas CLIs que você já usa e escuta a sua voz. Ele é opcional: desligue-o e o bando funciona sem ele.

> Versão 0.1, inicial. Os pacotes estão na [release mais recente](https://github.com/rogeriojunior31/Vults/releases/latest).
