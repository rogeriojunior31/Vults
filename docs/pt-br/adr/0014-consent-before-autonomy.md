# 0014. Uma nova regra de consentimento antes de qualquer autonomia
<!-- source: 8b52938f4721 -->

**Status:** Incorporada à [0004](0004-a-human-answers-permissions.md) em 2026-10-12.

Uma política que o usuário escreveu, viu como diff e aceitou com um clique pode responder a uma
permissão; um deny vence um allow, ações destrutivas sempre perguntam, e toda resposta é auditada.
