# 0007. Primeira release 0.1.0; um tema por versão até a 0.5
<!-- source: 4e4a79d3d02c -->

**Status:** Substituída pela [0015](0015-everything-by-0.2-in-small-releases.md), 2026-10-04. A
primeira release continua sendo a 0.1.0.

<a id="context"></a>

## Contexto

O checklist interno mirava uma primeira release chamada 1.0, mas boa parte do produto ainda está
por vir: mais formas de mostrar o bando, controle, histórico e, mais tarde, autonomia.

<a id="decision"></a>

## Decisão

- A primeira release é a **0.1.0**. Ela sai com o card do GitHub e os visuais sazonais do Zeca.
- Depois, um tema por versão:
  - **0.2 Experience**: mais superfícies na área de trabalho (bandeja, widget, notificações), foco,
    presença.
  - **0.3 Control**: ações rápidas nos pássaros, uma paleta de comandos, atenção que escala.
  - **0.4 Platform**: histórico local, projetos com sua branch, PR e CI, capacidades dos agentes.
  - **0.5 Operations**: o app completo, políticas e autonomia, iniciar agentes pelo app.
- Linux, KDE Plasma primeiro, até a 0.5. Windows e macOS vêm depois.

Os passos ficam no plano interno, `docs/dev/road-to-0.5.md`.

<a id="consequences"></a>

## Consequências

- 1.0 significa "pronto para Linux", depois da 0.5. A tradução pt-BR ainda espera por ela.
- A autonomia espera até que o app mostre e controle tudo bem, e até que a
  [0014](0014-consent-before-autonomy.md) seja aceita.
