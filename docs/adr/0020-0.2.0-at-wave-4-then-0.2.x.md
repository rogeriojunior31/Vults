# 0020. Releases: small and often, 0.2.0 at the N2 gate

**Status:** Accepted, 2026-10-10. Consolidated on 2026-10-12 from 0007 and 0015.
Amended on 2026-10-16 by [0031](0031-tasks-leave-vults.md): releases follow N0 to N4.

## Context

The first plan gave each version up to 0.5 one theme, which kept users waiting months for work
ready in days and made a version number promise a whole theme. The plan that followed
(`docs/dev/plan-zeca.md`) grew: Zeca's memory and work, a companion that speaks when it should, an
Android phone, and leftovers. Holding 0.2.0 until all of it is done would keep the Operations
milestone waiting for work it does not need.

## Decision

- The first release is **0.1.0**.
- Releases stay small and frequent. A patch number does not mean "fixes only", and may pass 9.
- Stages in [Plan Zeca](../dev/plan-zeca.md#order-of-work-2026-10-16) set the release gates:
  **0.1.9** after N0 (remove Tasks) and N1 (pages and theme), **0.2.0** after N2 (Flock and Chat),
  **0.2.1** after N3 (dictation), then **0.2.2** after N4 (the rest of the roadmap).
- An intervening fix takes the next patch; later stage numbers shift by one.
- Every release tag follows the human R3 smoke in the real app on the UI refined by N1
  ([0031](0031-tasks-leave-vults.md)). The wave 4 and U1/U13 gates no longer determine the tag.
  Native acceptance and automated CI remain required, separate from R3.
- Linux first through 0.2.x, with Android as the one exception
  ([0004](0004-a-human-answers-permissions.md)). Windows and macOS betas may land late in 0.2.x
  (plan-zeca X7); their full support comes after.
- 1.0 means "done for Linux".

## Consequences

- Users get each feature when it is ready; the changelog is per release.
- Steps once promised by 0.2.0 that the plan puts later (the command palette, open-mic voice, the
  side panel, the desktop bird, Vercel, the voice dictionary) arrive in 0.2.x.
- `plan-zeca.md`, *Order of work*, points at this record. Tasks and their review are no longer
  release requirements; `/continue`, spend and the budget remain covered by R3.

## History

- 0007, 2026-10-04: the first release is 0.1.0; one theme per version up
  to 0.5 (dropped by 0015).
- 0015, 2026-10-04: small 0.1.x releases, with
  everything planned by 0.2.0 (later narrowed to the wave 4 gate).
- 2026-10-16, [0031](0031-tasks-leave-vults.md): remove Tasks from the gate; release 0.1.9 after
  N0/N1 and 0.2.0 after N2, followed by N3 and N4, each after R3.
