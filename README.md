# Vultures AI

**A friendly flock watching your coding agents.** Zeca, an 8-bit vulture, perches on a wire at the
top of your screen with his flock, the vults, and shows what each Claude Code and Codex session is
doing, one animation per activity. Approve or deny permissions with a click, chat about files you
drop on him, and follow your GitHub pull requests and CI.

> **Status: early development (M0).** Nothing to install yet. The hook relay and its server work;
> the app itself does not exist yet.

Linux (Wayland) first, then Windows, then macOS. Built with Rust and Tauri.

- [Documentation](docs/README.md)
- [Architecture](docs/architecture.md)
- [Safety: what Vultures AI writes and never does](docs/safety.md)

Not to be confused with *Vulture*, the Python dead-code finder.
